# 02_OS website

Public page for [02_OS](https://github.com/csy20/02_OS). The image is a public alpha, not a production operating system.

The page is static HTML and the surface is white. On load it plays the same 2.6 second Zero Portal opening as the OS: the 2 slides behind the tall 0, the 0 grows in place, and the white veil opens through that oval.

The download button reads the newest GitHub release. Opening the page does not start the download. GitHub Pages serves this repository from the `main` branch.

The intended domain is `02os.xyz`. DNS is not pointed here yet.
